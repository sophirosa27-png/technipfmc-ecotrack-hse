# 🌐 TechnipFMC EcoTrack — Console de Monitoramento HSE Marítimo

Um sistema web **Full Stack** conceitual desenvolvido para automação, rastreabilidade e controle de resíduos industriais (Classe I e II) gerados a bordo de embarcações da frota offshore (foco na linha de navios PLSV *Skandi*). 

O projeto foi estruturado com foco em governança corporativa **ESG** e conformidade rigorosa com as diretrizes da **ISO 14001** (Gestão Ambiental) e normas do IBAMA.

## 🎯 Objetivos da Aplicação
* **Mitigação de Riscos de Contaminação:** Triagem imediata na inserção de resíduos Classe I (Perigosos) para garantir o armazenamento temporário seguro a bordo.
* **Inteligência de Dados para Auditorias:** Geração de logs digitais automáticos substituindo controles manuais em papel (Livro de Bordo), facilitando auditorias internas e externas.
* **Visualização de KPIs em Tempo Real:** Dashboard analítico integrado com métricas de desvio de aterro e taxas de reciclagem líquida da frota.

## 🛠️ Tecnologias Utilizadas
* **Back-end:** Node.js & Express API para controle de endpoints e persistência lógica.
* **Front-end:** React (com Hooks estruturados para reatividade) e Tailwind CSS para design responsivo no padrão corporativo.
* **Analytics:** Chart.js para renderização de gráficos dinâmicos de distribuição de resíduos.
